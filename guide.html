使用说明

上传手机截图

在编辑区顶部上传手机完整截图或顶部裁图，网页会自动提取状态栏并采用截图比例，无需选择手机型号。下方可看到提取结果。时间、信号、电量及截图里已有的灵动岛沿用原图。

默认保留原时间。填写“修改时间”即可替换数字；已有数字复用截图，缺少的数字匹配近似字体。勾回“保留原时间”可恢复。没有识别出可编辑时间时，会保留原状态栏。裁切不合适可展开“识别范围微调”。分析在本地完成，保存配置会包含截图。

生成图片

选择版式，修改运动名称、距离、时长和数据项。右上角可以选择导出宽度。预览和 PNG 使用同一套绘制逻辑；导出的图片包含原包字体和选定的素材。

字段与版式

完成详情按顺序展示全部可见数据项，支持两列或三列。地图卡有三个数据槽，轨迹海报有三个，跑步数据卡有两个，方形轨迹显示公里数。多出的字段保留在配置中，切换到完成详情即可展示。地图卡和跑步数据卡中的公里数独立显示。

导入与保存

“保存配置”会下载 JSON，包含数据、图片和轨迹，可再次导入。也可导入 basicInfo + sportData.list / columnSize 格式，数据项使用 title、valueStr、unit。

{
  "basicInfo": {"distance": 5000},
  "sportData": {
    "columnSize": 3,
    "list": [
      {"title": "平均配速", "valueStr": "6′00″", "unit": "/公里"}
    ]
  }
}

搜索地点

打开“画圈生成”，在顶部输入城市、公园或学校名称，点击“搜索地点”或按回车，再从结果中选择。地图会定位到该区域，随后可直接画圈。也支持输入“纬度,经度”。取消窗口可保留原记录，应用后城市名称和地图一起更新。

画一个圈自动生成

点击“画圈生成”，在地图上按住画一个大致闭合圈，松手自动细化。设置公里数和平均配速即可，细节工具默认收起。图片底图的单圈默认按 400 米估算，可在微调中修改；默认按圈线细化，地图有经纬度时按地理距离计算。也可手动选择联网道路贴合；外部道路服务不可用时会提示，可改用默认方式。

每圈有不同的局部偏移和透明叠加，上下弯与两侧保留不对称，距离与用时联动。可先点击“看看画圈效果”。这些是生成路线，不是恢复真实 GPS。默认的“按圈线细化”保留画出的形状，不检查地面障碍，可参照地图调整。

手机画面自定义

展开“时间字号、画面尺寸与底部样式”，可调整时间大小、自定义像素宽高、底部留白，以及安卓 / iOS / 隐藏手势条。保留原时间时直接使用原图，取消后才启用字号调整。应用尺寸后按设定宽高导出；全部设置随 JSON 保存。

便捷地图自定义器

点击预览旁的“自定义外观”，可直接展开地图外观面板。切换到“Keep 风格 · 可编辑地图”后，文字大小、深浅、字重、颜色，道路宽度、颜色、深浅，绿地与背景色，方向箭头开关与大小均可调整。提供默认、柔和、清晰预设；恢复外观不会清空路线或地点。图片底图无法拆开文字单独修改，仍可调整体明暗。

点击“地图与细节微调”展开高级工具。可画线、拖动节点、删除节点、分段涂配速、撤销重做，调整颜色、透明度、深浅、粗细、描边和起终点。按住地图拖动移动视角，滚轮缩放；修改完成后点击“应用到图片”。取消不会改动当前图片。

默认示例底图使用虚构路名与人工路线；Keep 风格可编辑地图使用提取的样式与矢量数据，并允许按手机效果微调。也可选高德地图或 OSM。可不导入轨迹直接在地图上画线，也可导入 GPX。GPS 坐标默认为 WGS84，高德 / Keep 坐标可在高级设置选择 GCJ-02。

合成地图中的彩色路线可以自动分离调深浅；改形状时可先修补底图，再画新路线。修补不是恢复原始地图，复杂区域可能残留，支持撤销。带时间戳的轨迹按配速着色；没有时间的线段显示正常色，也可手动涂色。

轨迹与底图

GPX 可读取经纬度、时间、海拔以及扩展中的心率和步频。CSV 支持 lat,lon,time,elevation 表头，或无表头的 lat,lon 两列。GeoJSON 支持 LineString 和 MultiLineString。勾选“同时应用”后，距离和时长会使用文件中的计算值；可取消勾选，保留自行输入的记录数据。

纯轨迹无需网络。上传图片可以使用指定地图底图。OpenStreetMap 使用真实经纬度绘制底图并附带来源标注，需要网络和 WGS84 坐标。在联网地图上手绘、拖动节点时保留经纬度；图片上的手绘点按图片坐标保存。

更多区块

仅完成详情显示附加区块。支持文字、更多指标、分公里配速、折线图和图片。折线图缺失值使用 null，会断开线条。

[
  {"type":"text","title":"运动感受","text":"今天的节奏很舒服。"},
  {"type":"metrics","title":"更多数据","list":[
    {"title":"累计爬升","valueStr":"38","unit":"米"}
  ]},
  {"type":"splits","title":"分公里配速","rows":[
    {"label":"1","pace":360},{"label":"2","pace":352}
  ]},
  {"type":"chart","title":"心率","unit":"次/分钟",
   "points":[[0,118],[1,142],[2,null],[3,150]]}
]

图片与字体

头像、海报背景、地图底图和二维码图片均支持本地上传。配置保存会包含这些图片。远程素材需要允许跨域读取才能导出。未上传二维码时，显示原包中的扫码图标，不会自动生成链接二维码。

地图卡、轨迹卡和数据卡以提取的原生设计尺寸为基础。完成详情支持动态长图；它的模块排布是网页版实现，按提供的截图对照实现，状态栏已做真实参考图像素检查，其余页面不宣称全图像素一致。
